Operations Ongoing

Homelab

26 services on Debian, run like production

Self-hosted

The place I get to be my own ops team, and where most of what I know about Docker, networking and Linux actually came from. The whole setup lives in one repository, with about 130 commits since September 2024.

  • 26 Docker Compose stacks, Nextcloud, Immich, Home Assistant and a Forgejo git server among them, behind Nginx Proxy Manager, with AdGuard Home as the network's DNS.
  • Tailscale for private access, VPN containers for outbound traffic, and a VPN on the home router itself.
  • Nightly Borg backups written in TypeScript on Bun: each run stops the affected stacks in dependency order, backs up, restarts them and checks they came back. A weekly job restore-tests the latest archive and integrity-checks the databases inside it.
  • Grafana, InfluxDB, Beszel and Scrutiny for metrics and disk health; Healthchecks.io and ntfy alert me when a job fails.
  • GitHub Actions validates every Compose file, shellchecks the scripts, lints the workflows and runs the tool tests. Actions are pinned to commit SHAs and kept current by Dependabot.
